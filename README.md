# Code pour la compétition Kaggle SDI-Metz

## Hierarchie

- Le dossier "notes" contiendra les notes sur ce qui est fait, et pourquoi c'est fait. 
- Le dossier "results" contiendra les résultats de chaque expérience
- Le dossier "scripts" contient des scripts utilisés pour du travail autour des modèles:
- - "denoising": appliquation d'un deblurring ou d'un denoising par Restormer
- - "group_classes": réannotation du dataset en plus grandes classes pour faire une pipeline en deux étapes.
